# IncidentHub – Project Spec

## Incident Fields
- id
- title
- type: AUTO, HOME, CYBER, FRAUD, OUTAGE, OTHER
- severity: 1–5
- status: OPEN, IN_PROGRESS, RESOLVED
- date: yyyy-mm-dd
- description

## Risk Score
riskScore = severity * 20

## Goal
A full-stack web application to log incidents and visualize risk and trends.
